## Configuration design

A specifically selected physical microphone is not replaced by changing Windows defaults. The verified bridge requires Codex to select CABLE Output. Proposed product setup: preserve prior microphone ID, configure a stable Snowball virtual input once, then route selected PC microphone or MK20 PCM to it; never simultaneously feed both unless explicitly requested. PC pass-through/source switch and automatic restoration are not implemented. App setting automation must be verified per version; do not spoof a physical endpoint identity.

Current PoC sends only Ctrl+Alt+Shift+F9 and cannot inspect native shortcut state. No matching binding means no successful start. Normal Codex Voice UI configuration was verified earlier; no public configuration API was established. Setup should check/guide or automate the visible settings, preserve previous binding, account for collisions, and require a fixture acceptance before declaring ready. Do not infer registration from SendInput success or reserve a shortcut by stealing it from Codex.
