## Defects exposed and fixed

- Real thread metadata exceeded the old 256 KiB receive bound. Native receives now have a finite 4 MiB limit; list pages are ten entries with ten-page/48 KiB normalized limits. Worker framing remains 64 KiB. Truncation is visible in snapshots/UI.
- Native completion previously left journal commands acknowledged. Successful matching completion now reconciles to completed, including completion-before-receipt races. Failed/interrupted notifications never fabricate successful inference.
- Native deltas can be larger than a plugin frame. Live projection retains a bounded tail with an explicit truncation flag instead of disconnecting or silently claiming a full transcript.

## Real approval request observation

`scripts/verify-codex-approval.mjs` used the same reviewed CLI and existing login with a separate **ephemeral** task and private temporary project. The prompt asked Codex to create a probe file there; the native app-server requested approval and advertised `accept` and `cancel` (no `decline` in this instance). The verifier chose **cancel**. The matching approval became `resolved`, while the answer command remained `unknown`; the middleware did not claim exact acceptance or silently retry. Output: `nativeApprovalSeen=true`, `safeRefusalOffered=cancel`, `clearedDecision=resolved`, `answerCommand=unknown`, `exactAcceptanceProof=false`, `preexistingTaskCommanded=false`. The temporary state was removed. An initial attempt assumed `decline` and was stopped before sending an answer; its private temporary state was inspected and safely removed. No pre-existing task was commanded or altered by either attempt.

The [official Codex App Server protocol](https://learn.chatgpt.com/docs/app-server#approvals) explicitly says `serverRequest/resolved` means the request was **answered or cleared**, including automatic cleanup. This real run confirms the conservative behavior. It does not satisfy the stronger exact-answer acceptance gate; keep that check blocked unless a correlated native receipt can be established.
