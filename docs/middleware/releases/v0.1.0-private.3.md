[Three-platform CI](https://github.com/fkiller/Snowball_Middleware/actions/runs/36081942461) passed real packaged tray/no-front-window/loopback-noAuth/pause smoke with 96/96 application hashes and 99 expected files. Both Mac jobs passed after `ditto` ZIP extraction. The Windows installer was built locally from the tagged source, installed to a clean path, smoke-tested and uninstalled successfully.

The local Web Supervisor intentionally has no login/PIN and binds only `127.0.0.1`; MK20 pairing is separate. On the owner's Windows PC, the installed runtime restored two ready projects, controllable Codex CLI and a read-only OpenCode observer. Actual Codex model/effort selection and separate verification-task commands work. OpenCode control remains disabled after its free provider rejected a structured server send with HTTP 403. A disposable Codex approval `accept` produced its temporary-file effect, but the protocol gave no unique answer receipt; the command remains unknown with no automatic retry.

MK20 currently appears only as an unsupported QMK USB HID candidate. The separate product CDC interface and authenticated pairing are absent/unverified, so this build has **no MK20 control or accepted physical voice integration**. The binaries are unsigned; Mac apps are not notarized. Signed user installation, OS login/sleep and production update/rollback remain unverified. This is a private developer preview, not a complete hardware middleware MVP. Public licensing is undecided.
