# Snowball Middleware v0.1.0-private

Private, unsigned development preview for the repository owner's Windows x64 and macOS ARM64 computers. The default Web Supervisor binds to `127.0.0.1` and intentionally has no PIN or Web authentication. The desktop app runs in the system tray with no front window; open the Supervisor from its tray menu. Device pairing is a separate process.

## Current capabilities and limits

On the owner's current Windows PC, the running packaged middleware restored two registered projects, an explicitly controllable Codex CLI connection and an OpenCode observer. Codex's actual native model and effort catalog is used; a new verification task previously completed a real GPT-6-Astra/low command. OpenCode control remains disabled because a new disposable server session's provider rejected structured send with HTTP 403. No existing user task was commanded during verification.

The connected MK20 currently appears as an unsupported QMK USB HID candidate. Its separate product CDC interface, vendor key-report contract and authenticated pairing have not been established; **this release does not provide MK20 control**. Voice capture and end-to-end physical control are not accepted. The bundled harness reference plugins are maintained in separate private repositories and prereleases; independently reviewed device plugins are not released.

These binaries are unsigned. The macOS ZIP has not been notarized or installed on a user's Mac; macOS x64 has not been built. Windows login/sleep lifecycle, another-user isolation, OS notifications, production update/rollback and publisher signing are unverified. Treat this as a private developer preview, not a production release or completed hardware middleware MVP. Public licensing is undecided.
