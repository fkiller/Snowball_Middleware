## Product requirements cross-check

- Preserve configured versus editing highlight, first-valid/remembered scoped selection, top session context and bottom voice/progress row.
- Workspace/Settings remain full-screen modals with top-left return; left knob scrolls vertical viewports, not automatic file selection. Do not infer a selected file from current directory.
- Questions have three scrollable option rows and fixed bottom custom-answer/voice actions; bind dictation to native question ID.
- Voice now additionally requires destination-bound editable draft, optional shared transcription host, installation on one host only, GPU-offline fallback and explicit user provider policy.
- Existing toggle recording is not hold-to-talk. Keep this distinction visible; decide/support both using key-down/up events rather than claiming equivalence.
- Actual active desktop task detection remains separate from most recent task; manual selection or a draft pins context.

The UI requirements above are retained design constraints, not a claim that every current hardware rendering path was retested.
